# Калькулятор и конвертер величин

Лабораторная работа №1. Консольное приложение на Python для вычисления
арифметических выражений и перевода единиц измерения.

## Возможности

### Калькулятор

- Поддерживаются целые и вещественные числа.
- Поддерживаются операции `+`, `-`, `*`, `/`.
- Поддерживаются унарные `+` и `-` перед числами.
- Игнорируются пробелы между токенами.
- Учитывается приоритет умножения и деления над сложением и вычитанием.

Обработка выражения разделена на три этапа:
разбиение на токены, проверка корректности и вычисление результата.

### Конвертер

Поддерживаемые группы:

- Длина: `mm`, `cm`, `m`, `km`.
- Масса: `g`, `kg`.
- Температура: `c`, `f`, `k`.

Правила:

- Регистр единиц не учитывается.
- Конвертация между разными группами запрещена.
- Температура ниже абсолютного нуля запрещена.
- Результат возвращается как `float`.

Длина и масса переводятся с помощью коэффициентов относительно метров
и килограммов. Для температуры используются отдельные формулы.


## Поддерживаемые команды

```powershell
python -m toolkit calc "EXPRESSION"
python -m toolkit convert VALUE --from UNIT --to UNIT
python -m toolkit --help
```

## Примеры использования

Вычисление выражения с учётом приоритета операций:

```powershell
python -m toolkit calc "2 + 3 * 4"
# 14.0
```

Вычисление с отрицательным числом:

```powershell
python -m toolkit calc "2 * -3"
# -6.0
```

Перевод массы:

```powershell
python -m toolkit convert 1.5 --from kg --to g
# 1500.0
```

Перевод температуры:

```powershell
python -m toolkit convert 0 --from c --to f
# 32.0
```

Использование единиц в верхнем регистре:

```powershell
python -m toolkit convert 2 --from KM --to M
# 2000.0
```

## Обработка ошибок

Калькулятор проверяет:

- Пустое выражение.
- Недопустимые символы.
- Отсутствующие операнды или операторы.
- Недопустимые сочетания операций.
- Некорректную запись числа.
- Деление на ноль.

Конвертер проверяет:

- Неизвестные единицы измерения.
- Несовместимые группы единиц.
- Температуру ниже абсолютного нуля.

Нечисловое значение аргумента `value` отклоняется при разборе аргументов CLI.

Коды завершения:

- `0` — успешное выполнение, результат выводится в `stdout`.
- `2` — ошибка, сообщение выводится в `stderr`.

```text
lab_01/
├── src/
│   └── toolkit/
│       ├── __init__.py
│       ├── __main__.py
│       ├── calculator.py
│       ├── converter.py
│       ├── constants.py
│       └── errors.py
├── tests/
│   ├── test_calculator.py
│   ├── test_converter.py
│   └── test_cli.py
```

Назначение основных файлов:

- `__main__.py` — разбор аргументов командной строки и запуск команд.
- `calculator.py` — разбор, проверка и вычисление выражений.
- `converter.py` — перевод единиц измерения.
- `constants.py` — таблица единиц и коэффициентов.
- `errors.py` — классы исключений.

## Команды проверки

### Тесты

Предусмотрено 12 автоматических тестов: тесты калькулятора,
конвертера и два теста CLI, в том числе и негативные сценарии.

Вычислительные функции тестируются прямыми вызовами без `subprocess`.
Для проверки CLI программа запускается отдельным процессом.

Запуск всех тестов:

```powershell
python -m pytest
```
